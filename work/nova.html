Nova

End-to-end encrypted chat and calling — rebuilt once already, from a Flutter original to its current Expo/React Native form, without losing the crypto or signaling architecture underneath.

Year
2025
Role
Solo founder & developer
Built with
Expo, React Native, Flutter, Supabase, WebRTC

The problem

Real-time messaging apps that claim end-to-end encryption rarely let a solo developer verify the primitives underneath. Nova was built to actually own that layer: X25519 key exchange, AES-256-GCM encryption, and WebRTC voice/video calling with signaling that never touches a server in cleartext.

My part

Solo founder & developer — architected both the current Expo/React Native rebuild and the original Flutter version end to end, including the crypto and calling layers in both.

Stack

  • Expo
  • React Native
  • Flutter (earlier version)
  • flutter_webrtc
  • Supabase (Realtime Broadcast)
  • WebRTC
  • X25519 / AES-256-GCM

Outcome

A real, working E2EE chat and calling app with WebRTC voice/video, backed by a real Supabase backend and Realtime Broadcast for signaling — rebuilt once already from Flutter to Expo/React Native without losing any of the underlying crypto or calling architecture.

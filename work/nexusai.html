NexusAI

An AI-powered learning web app with chat, an image generator and a step-by-step math solver, in a neon dark interface.

Status
Working web app
Focus
React, TypeScript, AI

What it is

NexusAI is a futuristic dark web app with frosted-glass panels and an animated particle background. A cloud backend runs the AI functions for chat and image generation.

What is in it

  • AI chat with replies that appear live as they are written, starter prompts, and help with explanations, homework, coding and creative tasks
  • Image generator with OpenAI or Stability AI engines, or both side by side, plus negative prompts, style presets and aspect ratios
  • Math problem solver: type a problem or upload a photo of homework and get step-by-step solutions across algebra, calculus, geometry, statistics and physics
  • Collapsible sidebar, sliding page transitions and hover animations

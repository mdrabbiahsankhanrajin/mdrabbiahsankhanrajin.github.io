Aurora Studio

A fictional AI-powered creative workspace for designing, organising, generating and analysing digital experiences.

Status
Concept prototype
Focus
Concept, Dark UI, Dashboard

What it is

Aurora Studio is a design exercise: one cinematic dark interface that combines project management, a visual page builder, generative AI tools, collaboration and reporting.

What is in it

  • Landing page, signed-in dashboard and a projects hub with progress, folders and version history
  • Visual workspace with layers, assets, a property inspector, publishing controls and an AI copilot
  • AI Canvas for generating websites, images, presentations and campaigns from prompts
  • Analytics and insights covering output, AI usage, team performance and suggested optimisations, plus a command palette

Status

Status: a frontend prototype populated with fictional sample content and data. It is a visual showcase, not a live product.

Focus

  • Concept
  • Dark UI
  • Dashboard
  • Design system
